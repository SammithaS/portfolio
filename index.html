Side Project 01 · Accounts Payable

SinoprexInvoice

An invoice PDF goes in. A cited, auditable decision comes out: approved, needs review, on hold or rejected.

~20policy-cited rule checks
4decision outcomes
₹0.01ERP read-back tolerance

  1. Read

    Gemini extracts every field from text or scanned PDFs, with page evidence and calibrated confidence. Low-confidence fields go to a person.

  2. Retrieve

    Hybrid RAG (pgvector + Postgres full-text, rank fusion) pulls the vendor's contract clauses and AP policy.

  3. Decide

    A pure-Python rules engine checks GST, arithmetic, duplicates, PO/GRN matching, bank changes and the approval matrix.

  4. Pause, post, verify

    LangGraph interrupts for review and survives restarts. Approved cases post to the ERP and are read back field by field.

Side Project 02 · IT Service Desk

Minocy IT Help

An edge-native self-service IT portal. The AI fixes it first; a human takes over cleanly, with everything already tried.

0servers to run
20knowledge base articles
5IT support teams routed

  1. Help first

    A supervisor agent hands off to Knowledge, Ticket and Access specialists, grounded in hybrid search over the KB.

  2. Escalate with context

    Tickets carry the full troubleshooting history. A triage agent sets priority and the right team.

  3. Run the lifecycle

    Durable Cloudflare Workflows handle SLA reminders, escalation, "Did this fix it?", close and reopen.

  4. Approve access by email

    "I need Figma" becomes a request the manager approves from a link. Password resets run the same way.
